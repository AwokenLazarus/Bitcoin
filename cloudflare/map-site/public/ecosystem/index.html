Run it yourself

Software

Everything below is open source and runs on ordinary hardware.

Bitcoin Knots (BLAKE2b) Node

The node this network runs. Version 29.4.2 or later enforces the current rules, including long coinbase maturity. Install script and reference config in our repository.

Node setup →

DATUM gateway Mining

Runs beside your node, builds your templates and talks to a pool's Prime. Several forks support this chain: CONVOY, iohzrd and FlyTheElephant, plus our own Rust lazarus-gateway.

CONVOY gateway →

Lazarus Prime Pool server

The pool side of DATUM, in Rust: verifies shares, issues the coinbase split, keeps the TIDES window and pays every miner inside the block that earned it.

Read the source →

Explorer Chain

A mempool-style explorer built for this chain's headers, with a public REST API and websocket for live blocks and transactions.

API docs →

Electrum server Wallets

Public endpoint for wallets that speak Electrum protocol 1.8 and understand 164-byte headers.

electrum.lazarus-xbt.xyz:50002:s

MCP server AI

Live pool and chain data for AI assistants that speak the Model Context Protocol. Point Claude or ChatGPT at it and ask about blocks, miners or payouts in plain language.

mcp.lazarus-xbt.xyz →
